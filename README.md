# Decision RAG

Decision RAG is a clean Streamlit application for document-grounded decision making. It combines page-aware PDF ingestion, source-scoped retrieval, a multi-agent reasoning pipeline, and Gemini for the final analysis.

## What changed from the old project

The rebuild removes the fragile Ollama compatibility layer, avoids import-time model downloads and Chroma assumptions, uses one configurable Gemini client, persists a self-contained local index, and makes every agent stage visible in the UI. If Gemini is unavailable, the app does not crash or hallucinate: it shows the retrieved evidence and the exact configuration problem.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env and set GEMINI_API_KEY
python -m streamlit run app.py
```

Open the URL printed by Streamlit. The starter PDFs in `data/documents/` are already indexed when this package is delivered; new PDFs can be uploaded from the left sidebar.

## Gemini configuration

`GEMINI_API_KEY` is required for the reasoning agents. `GEMINI_MODEL` defaults to `gemini-2.5-flash` and can be changed to a model enabled for the Google AI Studio key. The key is read only from the environment or `.env`; it is never written to the index. If the configured model is unavailable for your key, the app automatically retries compatible Gemini Flash model IDs and available models returned by the API.

## Pipeline

The router classifies the question as `FACTUAL`, `ANALYTICAL`, or `DECISION`. The retriever selects page-aware chunks from the selected document scope. The analyst extracts facts and uncertainty. For analytical and decision questions, the risk reviewer, options planner, decision lead, verifier, and final editor run in sequence. Evidence IDs such as `[E1]` link statements back to the displayed PDF chunks.

## Data files

PDFs live in `data/documents/`. The derived index lives in `data/index.json` and can be safely deleted and regenerated by re-indexing the PDFs. No prebuilt Chroma database is required.

## If the app says the model is unavailable

Open `.env` and set `GEMINI_MODEL` to a model enabled in your Google AI Studio account, for example `gemini-2.0-flash` or `gemini-2.5-flash`. Restart Streamlit after changing `.env`. The rebuilt client also tries compatible fallback models automatically, so you usually only need to restart and ask the question again.
